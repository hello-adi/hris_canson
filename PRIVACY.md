# Privacy Policy — Hris Canson

**Last updated:** 2026

Hris Canson is a browser extension that interrupts you on websites you choose, so you can rethink impulse habits. Privacy is part of the product.

## Summary

- **No analytics.**
- **No tracking.**
- **No accounts** with us.
- **No ads.**
- **Everything stays in your browser.**

## What data is stored

The extension stores only:

| Data | Where | Purpose |
|------|--------|---------|
| List of websites you add | Browser extension storage (`storage.sync`) | Know which sites should show an intervention |
| Category per website (Shopping, Social, Entertainment, Other) | Same | Pick a fitting intervention message |

Confessions typed in the overlay are **not saved**. They appear briefly on screen and are discarded.

## What we do not collect

We do not collect, transmit, or sell:

- Browsing history
- Confessions or free-text input
- Personal identifiers
- Location
- Payment information
- Analytics or telemetry

There is **no backend server** for this extension. There is no Hris Canson account system.

## Browser sync

If you enable your browser’s built-in sync (Chrome Sync / Firefox Account), the website list may sync across *your* devices via the browser vendor. That data is not sent to the extension author.

## Network requests

The extension may load fonts from Google Fonts when the popup or intervention UI is shown. That is a third-party request for typography only. No extension data is uploaded to Google as part of the product logic.

Images and scripts for the extension itself are packaged with the extension and served locally.

## Permissions

| Permission | Why |
|------------|-----|
| `storage` | Save your watchlist |
| `tabs` | Detect navigations so interventions can appear after soft (SPA) navigations |
| `scripting` | Show the intervention overlay on matching pages |
| Host access | Run on sites you visit so matching hosts can be intervened |

The extension only shows the full intervention UI on hosts you have added to the watchlist.

## Children

This extension is not directed at children and does not knowingly collect children’s data.

## Changes

If this policy changes in a meaningful way, the date at the top will be updated and the repository changelog will note it.

## Contact

Open an issue on the project’s GitHub repository for privacy questions or requests.
